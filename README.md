# STM32 OLED Voltage Meter

## 项目简介

本项目是一个基于 STM32 HAL 库的嵌入式电压测量小程序。

项目通过 STM32 的 ADC 采集分压电路输出电压，并根据 ADC 原始值、参考电压和分压比例计算实际输入电压，最后通过 OLED 屏幕实时显示测量结果。

当前项目已经完成：

- ADC 电压采样
- 分压电路测量
- OLED 显示
- I2C 地址扫描调试
- Keil / STM32CubeMX HAL 工程整理
- GitHub 项目记录

本项目是后续扩展为嵌入式测量小仪器的基础版本。

---

## 项目功能

- 使用 STM32 ADC 采集模拟电压
- 使用电阻分压电路保护 ADC 引脚
- 使用 OLED 显示测量结果
- 支持通过实际参考电压进行软件校准
- 支持 I2C 外设地址扫描，便于调试 OLED 等模块
- 工程基于 STM32 HAL 库，适合使用 Keil 和 STM32CubeMX 学习

## 硬件接线

### OLED 接线

| OLED 引脚 | STM32 引脚 | 说明 |
|---|---|---|
| SCL / SCK | PB6 | I2C 时钟线 |
| SDA | PB7 | I2C 数据线 |
| VCC | 3.3V / 5V | OLED 电源 |
| GND | GND | 共地 |

说明：有些 OLED 模块会把 I2C 时钟线标成 `SCK`，在本项目中可理解为 `SCL`。

### 电压分压采样电路

```text
被测电压正极 ---- R1 100.3kΩ ---- 分压点 ---- R2 15.66kΩ ---- GND
                                      |
                                      |
                                     PA0
```

PA0 接到 R1 和 R2 中间的分压点，不可以直接接被测电压正极。

## ADC 测量原理

STM32 的 ADC 会把输入电压转换成数字量。

本项目使用 12 位 ADC，因此 ADC 原始值范围为：

```text
0 ~ 4095
```

ADC 电压计算公式：

```c
v_adc = adc_raw / 4095.0f * ADC_REF;
```

其中：

```c
#define ADC_REF 3.297f
```

`ADC_REF` 是当前实测的单片机参考电压。

由于前端使用了电阻分压，所以实际输入电压需要乘以分压倍数：

```c
v_in = v_adc * (100.3f + 15.66f) / 15.66f;
```

当前电阻分压倍数约为：

```text
(100.3 + 15.66) / 15.66 ≈ 7.405
```

所以：

```text
输入电压 ≈ ADC 采样点电压 × 7.405
```

在 ADC 参考电压约为 3.297V 时，理论最大可测输入电压约为：

```text
3.297 × 7.405 ≈ 24.4V
```

实际使用时建议保留余量，不要让 PA0 采样点电压超过 3.3V。

## ADC 采样代码片段

```c
HAL_ADC_Start(&hadc1);

if (HAL_ADC_PollForConversion(&hadc1, 10) == HAL_OK)
{
    adc_raw = HAL_ADC_GetValue(&hadc1);
}

HAL_ADC_Stop(&hadc1);
```

ADC 转换代码：

```c
#define ADC_REF 3.297f

v_adc = adc_raw / 4095.0f * ADC_REF;
v_in = v_adc * (100.3f + 15.66f) / 15.66f;
```

## I2C 调试说明

本项目使用 I2C OLED，因此在调试 OLED 时，可以先使用 I2C 地址扫描代码确认模块是否正常连接。

I2C 扫描可以帮助检查：

1. OLED 是否正常供电
2. GND 是否共地
3. SCL / SDA 是否接反
4. CubeMX 中 I2C 是否配置正确
5. OLED 的实际 I2C 地址是多少

OLED 常见 7 位地址：

```text
0x3C
0x3D
```

STM32 HAL 的 I2C 函数通常需要传入左移一位后的地址，例如：

```text
0x3C << 1 = 0x78
```

所以有些教程写 `0x3C`，有些代码写 `0x78`，它们可能表示的是同一个 OLED。

## 如何打开工程

1. 使用 STM32CubeMX 打开 `.ioc` 文件，查看外设配置。
2. 使用 Keil 打开 `Firmware/MDK-ARM/` 目录下的工程文件。
3. 编译工程。
4. 下载程序到 STM32 开发板。
5. 按照硬件接线连接 OLED 和分压电路。
6. 上电后观察 OLED 显示的电压值。

## 安全注意事项

- PA0 只能接分压点，不能直接接高电压。
- 被测电压负极必须和 STM32 GND 共地。
- 接入 STM32 ADC 前，建议先用万用表测量分压点电压。
- 分压点电压不要超过 3.3V。
- 不要在带电状态下随意切换万用表到电阻档或蜂鸣档。
