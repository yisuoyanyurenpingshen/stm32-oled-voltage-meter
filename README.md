# STM32 OLED Voltage Meter

## 项目简介

这是一个基于 STM32、ADC 和 OLED 的电压测量小程序。

项目通过 STM32 的 ADC 采集输入电压，并将计算后的电压值显示在 OLED 屏幕上。

## 当前功能

- 使用 ADC 采集模拟电压
- 使用 OLED 显示测量结果
- 支持基础电压换算
- 已完成基础程序测试

## 使用硬件

- STM32 开发板
- OLED 显示屏
- 电阻分压电路
- 杜邦线 / 面包板

## 学习目标

通过这个项目学习：

- STM32 HAL 基础使用
- ADC 电压采样
- OLED 显示
- 嵌入式项目整理
- GitHub 项目记录
